SITE WEB — SALON INTERNATIONAL DU JEU VIDÉO
================================================

Contenu :
- index.html : accueil
- salon.html : présentation et objectifs
- programme.html : axes et activités envisagées
- exposants.html : informations et manifestation d'intérêt
- partenaires.html : partenariats et sponsoring
- actualites.html : espace actualités
- contact.html : contact
- mentions.html : informations prévisionnelles
- assets/style.css : design responsive
- assets/main.js : menu mobile et formulaires mailto

OUVRIR LE SITE SUR VOTRE ORDINATEUR
1. Décompressez le fichier ZIP.
2. Ouvrez le dossier.
3. Double-cliquez sur index.html.

PUBLIER GRATUITEMENT AVEC GITHUB PAGES
1. Créez un compte sur https://github.com/
2. Créez un nouveau dépôt public (par exemple salon-jeu-video).
3. Téléversez TOUS les fichiers et dossiers de ce site à la racine du dépôt.
   Important : index.html doit être à la racine, et le dossier assets doit rester à côté.
4. Dans le dépôt, ouvrez Settings > Pages.
5. Dans Build and deployment, choisissez Deploy from a branch.
6. Choisissez la branche main et le dossier / (root), puis Save.
7. Attendez la publication. GitHub affichera l'adresse publique du site.

FORMULAIRES
Les formulaires Exposants, Partenaires et Contact préparent un courriel avec mailto.
Ils ouvrent le logiciel de messagerie du visiteur et ne stockent ni n'envoient
automatiquement les réponses. Pour recevoir des formulaires directement sur le
site, il faudra ensuite connecter un service de formulaire (certains proposent
une offre gratuite) ou un formulaire Google.

À PERSONNALISER AVANT PUBLICATION
- Confirmer les dates de l'événement.
- Confirmer le lieu : l'UAC est indiqué comme lieu envisagé, sous réserve de confirmation.
- Ajouter les liens de réseaux sociaux officiels.
- Ajouter les mentions légales et la politique de confidentialité adaptées à DMSO.
- Vérifier que l'adresse dmserviicesonline@gmail.com est bien celle à utiliser.
- Ne pas afficher de sponsors/partenaires avant confirmation écrite.

Le site est une première version statique. Il n'inclut pas de CMS, d'espace
administrateur, de billetterie ni de base de données. Pour modifier les textes,
il faut éditer les fichiers HTML/CSS (ou me demander de faire les changements).
